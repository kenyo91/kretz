# Kakeo (Flutter)

## Obtener la APK sin instalar nada (GitHub)
1. Crea un repositorio en github.com y sube el contenido de esta carpeta (incluida `.github`).
2. Pestaña **Actions** > **Build APK** > espera ~5 min.
3. Descarga `kakeo-apk` y pasa `app-release.apk` al móvil Android (permite "orígenes desconocidos").

## Con Flutter instalado
`bash setup.sh`
